未定义的 CSS 变量
StatusBar.vue 中引用了 --color-success-soft 和 --color-danger-soft，但 themes.css 中从未定义。这将导致离线/在线状态徽章背景色显示异常。

!
WelcomePanel 缺少 category 颜色变量
WelcomePanel 引用了 --cat-market、--cat-trading 等 11 个分类色变量，但 themes.css 中全部缺失。分类图标颜色无法渲染。
frontend/src/terminal/panels/WelcomePanel.vue:185-206
!
App.vue 的 body class 重复挂载
App.vue 的 div.app 上同时绑定 theme-${session.ui.theme} 和 density-${session.ui.density}，但 theme store 已经在 body 上挂载了这些类。类名重复，可能导致样式冲突。
frontend/src/App.vue:40
颜色与对比度 P1
1
深色主题面板层级糊在一起
App 背景 #0b0f19 和面板背景 #121929 对比度仅 0.03，Dock 内的面板与面板之间几乎无法区分。缺乏微妙的阴影/边框来建立层级。
2
边框颜色过浅
深色模式下 --color-border: #1e2d4d 在 #121929 背景上几乎不可见。卡片、表格、输入框的边框失去了应有的视觉分隔作用。
3
次要文字颜色层级不足
--color-text-secondary: #94a3b8 和 --color-text-tertiary: #64748b 差异太小，在 13px 基础字号下难以区分标题和辅助信息。
排版与布局 P1
1
字号偏小，桌面端可读性差
基础字号 13px，表格表头 10px，badge 10px，在桌面大屏幕上显得拥挤。建议桌面端至少 14px 基础字号，表头 12px。
2
中文表头不该 uppercase
PanelTable 的表头设置了 text-transform: uppercase，中文无大小写概念，此样式无意义且可能导致部分字体渲染异常。
frontend/src/terminal/components/panel/PanelTable.vue:131
3
GovDataPanel 卡片硬编码样式
indicator-card 使用了 border-radius: 8px 和 padding: var(--card-padding) 但未继承 PanelCard 组件的样式，导致卡片 hover 效果与其他面板不一致。
frontend/src/terminal/panels/GovDataPanel.vue:688-705
交互体验 P1
1
面板聚焦态缺失
Dock 内的多个面板同时显示时，用户无法直观知道哪个面板是"当前激活"的。没有聚焦边框、阴影或高亮效果。
2
Tab 拖拽没有视觉反馈
DockTab 的拖拽仅设置了 opacity: 0.4，缺少放置区域指示、拖拽占位符等更明确的反馈。
3
空状态过于简陋
EmptyState 组件只有图标+标题，缺少引导性操作（如"打开面板"、"刷新数据"）。对于金融终端来说，空状态应该提供下一步行动。
一致性 P2
1
面板样式风格不一致
MarketOverview 使用 PanelCard 组件，GovData 自己写卡片，Watchlist 使用 flex row。三个面板三种视觉风格，缺乏统一的设计语言。
2
border-radius 硬编码遍地
GovDataPanel 中 border-radius: 8px、6px，WelcomePanel 中 border-radius: 12px，但 CSS 变量定义的是 4px/6px/10px。多处未使用设计令牌。
做得好的地方 亮点
+
主题系统设计完善
Dark/Light + 3 密度级别 + CN/US 颜色方案，全部通过 CSS 变量实现，切换无闪烁。这是目前做得最好的部分。
+
CommandBar 交互精致
模糊背景、分类头、键盘导航、动画入场，设计水平明显高于其他组件。可以作为标杆组件。
+
LoadingState 骨架屏有 shimmer 动画
三种骨架类型（table/card/chart）都有 shimmer 加载动画，用户体验不错。
+
SignalBadge 设计精致
带发光效果的 dot + 文字标签，三种信号状态清晰，大小变体灵活。组件化程度高。
改进建议优先级

Phase 1：修复缺陷（1-2天）

  • 在 themes.css 中定义缺失的 --color-success-soft、--color-danger-soft、--cat-* 系列变量
  • 修复 App.vue 的 body class 重复挂载

Phase 2：提升视觉层级（2-3天）

  • 深色模式下面板背景增加与 app 背景的对比度（如 #0d1321 到 #151e32）
  • 增强边框可见度，或使用更清晰的 box-shadow 分隔面板
  • 为 Dock 激活面板添加聚焦态：2px accent 色边框或底部 glow 效果
  • 统一所有面板卡片的样式，全部使用 PanelCard 组件

Phase 3：交互优化（2-3天）

  • Tab 拖拽时增加 drop indicator（占位符线）和 ghost preview
  • EmptyState 增加 action 引导（如"刷新数据"、"打开面板"按钮）
  • 面板切换时添加微动画（fade/slide），避免内容"闪现"
  • PanelTable 表头取消 uppercase，优化中文排版

Phase 4：品牌化（可选，1-2天）

  • 增加一个 subtle 的网格背景或噪点纹理，提升终端"专业感"
  • 在 Header 和 StatusBar 添加更精致的渐变分隔线
  • 为重要 KPI 数据添加数字变化动画（如 +1.23% 的计数滚动效果）
