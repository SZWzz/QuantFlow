# P0-P2 评审问题修复规范

## Motivation

2026-07-30 全面评审发现 29 个问题（6 P0 + 11 P1 + 12 P2），涵盖 Go 后端、Vue 前端、Python sidecar、CI/文档四个维度。本文档定义修复方案。

## 分阶段方案

### Phase 1 — Python P0 紧急修复（数据损坏/崩溃风险）

| 问题 | 位置 | 修复方案 |
|------|------|---------|
| RLPredict proto 类型不匹配 | `proto/ml.proto` + `ml/engine.py` | proto 中 `observation` 从 `bytes` 改为 `repeated double`；Python 端 `np.array(request.observation)` 保持兼容 |
| BatchAnalyzeSentiment 无文本参数 | `proto/sentiment.proto` + `research/sentiment_service.py` | proto 增加 `text_contents` repeated string 字段；Python 端遍历处理；Go 端更新调用 |
| HealthServer.__del__ 事件循环访问 | `health/health_server.py` | 删除 `__del__`；改用 `AsyncExitStack` 注册清理回调 |
| grpcio-tools 运行时依赖 | `pyproject.toml` | 从 `[project.dependencies]` 移除，加入 `[build-system] requires` |

### Phase 2 — Vue 前端类型安全修复

| 问题 | 位置 | 修复方案 |
|------|------|---------|
| `(window as any).go` 68 处调用 | stores + composables + 组件 | 全部迁移到 `@/lib/wails` 类型化包装函数 |
| `any`/`as any` 418 处 | 全域 | 为 `AppMethods` 接口添加具体返回类型；商店中替换 `as any` 为具体类型 |
| `data.ts` 未用 `useWailsApp` | `stores/data.ts` | 迁移到 `@/lib/wails` 包装函数 |
| `export.ts` 4 个小写函数重复 | `lib/wails.ts:675-701` | 删除旧版小写函数 |
| 三模后端访问不一致 | 全域 | 统一到 `@/lib/wails` 包装函数 |
| Settings store 双来源存储 | `stores/settings.ts` + `useThemeStore` | 合并到 settings store |

### Phase 3 — Go/Python 架构修复

| 问题 | 位置 | 修复方案 |
|------|------|---------|
| 缠论模块零测试 | `python/src/chanlun/` | 添加碎形、笔、中枢基础单元测试 |
| 策略模块零测试 | `python/src/strategies/` | 添加信号生成单元测试（每个策略至少 1 个测试） |
| ML 模型字典无淘汰 | `python/src/ml/engine.py` | 添加 LRU+TLL 策略，可选基于 `cachetools` |
| AKShare HK 分钟缓存无淘汰 | `python/src/data/fetcher.py` | 添加 `functools.lru_cache` 或有界 dict |
| Python server 无信号处理 | `python/src/server.py` | 添加 SIGTERM/SIGINT 处理，gRPC graceful shutdown |
| Python 数据获取器同步 I/O | `python/src/data/fetcher.py` | `requests` → `httpx.AsyncClient` |
| Go `context.Background()` 不安全 | `app_startup.go` | QuotePoller/MinutePoller 使用可取消 context |
| 缺少 `gosec` linter | `.golangci.yml` | 添加 gosec 到 linter 列表 |

### Phase 4 — CI/文档/配置修复

| 问题 | 位置 | 修复方案 |
|------|------|---------|
| Taskfile.yml YAML 重复 key | `Taskfile.yml:25-26` | 删除重复行 |
| 缺少 workflow_dispatch | `.github/workflows/*.yml` | 所有 workflow 添加 `workflow_dispatch` |
| Coverage CLI flags 可能不解析 | `coverage.yml` | 阈值移入 `vitest.config.ts` 或在 CLI 使用正确格式 |
| 缺少 CONTRIBUTING.md | 根目录 | 添加贡献指南 |
| 缺少 SECURITY.md | 根目录 | 添加安全策略 |
| 缺少 Dependabot 配置 | `.github/` | 添加 Go/npm/pip 依赖更新配置 |
| env.example 缺少 key 和注释 | `.env.example` | 补充 QOS_API_KEY 等缺失变量和描述 |
| Go 版本硬编码 | CI workflow | 统一使用 `go-version-file: go.mod` |
