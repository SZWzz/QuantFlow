## 1. 浮窗面板 (Tear-off Windows)

### 规划
对标 某终端项目 ADS 的 `tear_off_to_new_frame` — 将面板拖出主窗口成为独立窗口。

### 缺失组件
| 组件 | 说明 |
|------|------|
| Wails 多窗口 API 集成 | 新建 Wails 窗口，渲染独立 Vue 组件 |
| DockTab 撕下按钮 | 面板标签栏的浮动按钮 |
| 独立窗口状态同步 | 数据/主题/Store 与主窗口实时同步 |

### 工作量估算: ~3 天

## 2. 离线模式

### 规划
桌面终端核心优势 — 无网络也能工作。L0/L1 缓存 → 离线 UI 指示 → 网络恢复后批量补充。

### 缺失组件
| 组件 | 说明 |
|------|------|
| 网络检测 goroutine | 每 30s ping 检测网络 |
| 离线状态管理 | `dataStore.isOffline` 联动 UI |
| 离线指示器 | StatusBar 显示"离线 | 数据截止 XX:XX" |
| 请求队列 | 网络恢复后自动重放积压请求 |

### 工作量估算: ~2 天
