### P0-2：ValuationBand（PE/PB Band）

**定位**：个股估值水位一目了然

**数据支持**：✅ 齐备
- 历史 PE：QuoteSnapshot.Pe (实时) + OHLCV 收盘价 × 历史股本 / 历史净利润 推算
- 简化方案：用 Close 走势 + 5 条均值倍乘通道替代传统 PE Band（数据通用性更强）
- PE 当前值 vs 5 年历史分位：FinancialsService.ComputeRatios().PE + OHLCV 历史

**面板设计**：

│ │  ── PE=35x (+1σ)                                                   │ │
│ │  ── PE=25x (均值)                                                   │ │
│ │  ── PE=15x (-1σ)                                                   │ │
│ │  ── PE=8x  (历史最低)                                              │ │
│ └────────────────────────────────────────────────────────────────────┘ │
│ 当前 PE: 22.5x | 历史分位: 35% | 均值: 25x | +1σ: 35x | -1σ: 15x     │
│ 当前 PB: 8.2x  | 历史分位: 60% | 均值: 6.5x                          │

**文件**：

| Plan | 需要新增数据 | 难度 | 方案 |

## 风险 / Trade-off

- **AKShare 速率限制**：`macro_cn.py` 54 个快速 endpoint + 25 个慢速 endpoint。慢速 endpoint（60-120s）在 `get_summary()` 中做了并发，但首次加载可能较慢。→ 缓存结果到 SQLite，面板打开时先展示缓存。
- **PE Band 精度**：简化版 PE Band 使用收盘价倒推历史 PE，依赖历史股本数据。→ 优先使用 mootdx 的 F10 财务快照（含历史 EPS）。
- **行业分类差异**：申万 vs 中信 vs GICS 分类体系不同。→ v1 用东方财富行业板块（最广覆盖），后续支持切换。
