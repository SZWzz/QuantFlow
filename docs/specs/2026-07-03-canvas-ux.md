# Canvas UX Enhancements: Keyboard Shortcuts + Flow Animation

## Motivation
The workflow canvas lacks keyboard shortcuts for common operations (Delete, Ctrl+C/V, Ctrl+A, Ctrl+Z) and has no visual feedback during execution (static edges, no flow animation). ComfyUI has both: keyboard shortcuts for power users and animated edge flows during execution.

## Design

### Part A: Keyboard Shortcuts

Implemented as a composable `useCanvasShortcuts.ts` registered in WorkflowCanvas.vue:

| Shortcut | Action |
|---|---|
| `Delete` / `Backspace` | Delete selected node |
| `Ctrl+C` | Copy selected node(s) |
| `Ctrl+V` | Paste copied node(s) at cursor offset |
| `Ctrl+A` | Select all nodes |
| `Ctrl+Z` | Undo |
| `Ctrl+Shift+Z` | Redo |
| `Ctrl+D` | Duplicate selected node |
| `Escape` | Deselect all / close context menu |
| `Ctrl+Enter` | Run workflow |

### Part B: Flow Animation on Edges

During execution, edges that carry data animate with a dashed flow effect (moving dashes like ComfyUI). After execution completes, edges show static with a subtle color change (success = green, error = red).

**Approach:** CSS animation on the edge SVG `<path>`. vue-flow supports custom edge styles via the `style` prop.

```css
@keyframes flow {
  0% { stroke-dashoffset: 20; }
  100% { stroke-dashoffset: 0; }
}
.edge-flowing {
  stroke: #58a6ff;
  stroke-dasharray: 5 3;
  animation: flow 0.5s linear infinite;
}
.edge-success {
  stroke: #3fb950;
  stroke-width: 2;
}
.edge-error {
  stroke: #f85149;
  stroke-width: 2;
}
```

### Data Flow

```
WorkflowExecution (Go backend)
    ↓ (Wails IPC: execution status updates)
WorkflowStore (Pinia)
    ├── executionStatus: 'idle' | 'running' | 'success' | 'failed'
    ├── nodeStatuses: Map<nodeId, { status: string }>
    └── edges: Edge[]
            ↓ (computed)
    edgeStyles computed property
            ↓ (bound via :edge-styles prop)
    WorkflowCanvas.vue (VueFlow component)
            ↓ (CSS animation on SVG <path>)
        Animated edges
```

### New/modified files:
- `frontend/src/workflow/canvas/WorkflowCanvas.vue` — register shortcuts, edge animation styles
- `frontend/src/lib/useCanvasShortcuts.ts` — new composable
- `frontend/src/stores/workflow.ts` — clipboard, copyNodes, pasteNodes, selectAllNodes, undo/redo

### API changes:
- WorkflowStore: add `clipboard`, `copyNodes()`, `pasteNodes()`, `selectAllNodes()`, `cloneNode()`, `undo()`, `redo()` methods
- WorkflowStore: expose `executionStatus` and `nodeStatuses` for edge color computation
- No Go backend changes required (all frontend-only)

## Acceptance Criteria
- [ ] Delete/Backspace removes selected node
- [ ] Ctrl+C/V copies/pastes nodes
- [ ] Ctrl+A selects all
- [ ] Ctrl+Z/Shift+Z undo/redo
- [ ] During execution, active edges show flowing dash animation
- [ ] After execution, edges turn green/red based on downstream node status

## Risks / Trade-offs
- Undo/redo requires a history stack in the store — memory usage grows with node count. Cap history at 50 entries.
- Edge animation CSS may not render smoothly on low-end GPUs. Consider using `will-change: stroke-dashoffset` on the edge paths.
- Keyboard shortcuts must not interfere with input fields — already guarded by the `isInput` check.
