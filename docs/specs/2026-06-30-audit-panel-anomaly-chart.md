# 审计面板：异常发现折叠 + 趋势图

## Motivation

当前 AuditPanel 的异常发现展示所有期次的数据，信息密度过高。用户只关心最新期有哪些异常，历史重复异常应折叠为"趋势"。同时缺少可视化趋势图辅助分析。

## Design

### 异常发现拆分

`allFindings` 按 `is_latest` 分为两组：
- **最新异常**：`is_latest === true` 正常展示
- **趋势异常**：`is_latest === false` 折叠在"趋势发现"下，标注持续期数

### ECharts 趋势图

在"财务历史"表格上方新增 ECharts 折线图：
- X 轴：报告期（降序，最新在右）
- Y 轴左：营收、净利润（亿元）
- Y 轴右：ROE、毛利率、负债率（%）
- 双 Y 轴，可切换显示指标

### 修改文件

| 文件 | 改动 |
|------|------|
| `AuditPanel.vue` | 异常发现拆分最新/趋势；新增 ECharts 折线图 |

### 示例

```
┌─ 异常发现 (3) ──────────────────────────────┐
│ 🔴 应收/营收比 48.2%   (最新)                │
│ 🟡 有息负债/总资产 32.1% (最新)              │
│ ▸ 趋势发现 (2)  [展开▼]                      │
│   🟡 商誉/净资产 8.5% 持续 3 期              │
│   🟢 毛利率波动 持续 2 期                    │
└─────────────────────────────────────────────┘

┌─ ECharts 折线图 ────────────────────────────┐
│  营收 ─ 净利润 ─ ROE ─ 毛利率 ─ 负债率       │
│  [图表区域]                                  │
├─────────────────────────────────────────────┤
│  财务历史 (12期)                             │
│  ..........                                 │
└─────────────────────────────────────────────┘
```

## Acceptance Criteria

- [ ] 异常发现按 is_latest 分组，仅最新期默认展示
- [ ] 非最新期异常折叠在"趋势发现"下，标注持续期数
- [ ] 新增 ECharts 双 Y 轴折线图（营收/净利润 左轴，ROE/毛利率/负债率 右轴）
- [ ] 图表响应面板宽度
- [ ] vue-tsc 通过
