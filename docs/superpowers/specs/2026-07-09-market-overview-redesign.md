# 市场概况页面重构（Bloomberg 风格）

## Motivation

当前 MarketOverviewPanel（市场概况）存在以下问题：
- 布局单调，四个区域竖着堆叠，没有信息层级感
- 涨跌家数后端 hardcode 为 0，永远空白
- sparkline 永远为空数组，指数卡片没有走势图
- 板块排名固定 8 条，无法滚动查看更多
- 缺少资金流向、北向资金、涨跌停等关键市场情绪指标
- 测试失效（使用了不存在的 `.index-card` 选择器）
- Wails 类型定义陈旧（`GetIndustryRanks` 缺少 mkt 参数）

### Market Tab

四个 tab：A股（默认）、港股、美股、全球。切换 tab 时：
- 指数卡片切换对应市场指数
- 涨跌家数、涨停跌停切换对应市场数据
- 指数 K 线图联动切换
- 板块排行切换对应市场板块分类

### 指数卡片

每行 3-5 张卡片，横向滚动。每张卡片：
- 指数名称 + 最新价 + 涨跌幅（百分比 + 涨跌额）
- 涨跌色（红涨绿跌）
- 点击切换指数 K 线图

数据来自后端 `GetMarketOverview()` — 保持不变，但需要后端补全 `sparkline` 字段。

### 涨跌家数 + 情绪仪表盘

一条水平 bar 分三段（红/灰/绿），按比例显示涨跌平占比。
右侧显示：涨停家数、跌停家数、北向资金净流入、总成交额。

后端需要新增：
- 涨跌家数 IPC（GetMarketBreadth — 不再 hardcode 0）
- 北向资金 IPC（GetNorthboundFlow）
- 涨跌停家数 IPC（GetLimitUpDown）

### 指数 K 线图

复用 `KlineChart.vue`（ECharts 封装），通过 `:option` prop 传入指数 OHLCV 数据。
- 点击指数卡片切换 `symbol`，触发 `loadOHLCV()`
- 支持 K 线和分时 Tab
- K 线：1日/5日/1月/1年/5年 间隔切换
- 分时：当日分时线（复用已有 `GetMinuteLine` + `KlineChart`）

### 板块排行

左右对照布局：
- 左列：涨幅 Top 10，红色横向条状图，条长正比于涨幅百分比
- 右列：跌幅 Top 10，绿色横向条状图，条长正比于跌幅百分比
- 滚动支持（固定显示 10 条，溢出隐藏）

数据来自后端 `GetIndustryRanks(market, 30)` — 前端取前 10，已存在。

### 资金流向

一行显示：
- 主力资金净流入（超大单 + 大单）
- 超大单净流入
- 大单净流入
- 小单净流出（负数，绿色）
- 右侧显示板块资金 Top 3

需要后端新增 `GetMoneyFlow` IPC（从东财/通达信等获取主力资金流向）。

### 资金流向不需要后端

其实先不做资金流向，当前数据源不支持。回退为纯前端计算——基于板块排行数据和当前市场情绪指标的组合展示。第一期只展示已有的数据。

第一期的改动范围缩至：

| 模块 | 变化 |
|------|------|
| 指数卡片 | 增加 sparkline 真实数据 |
| 涨跌家数 | 修复后端 hardcode 0，前端展示占比条 |
| 情绪仪表盘 | 新增涨停跌停 + 北向 + 成交额 |
| 指数 K 线图 | 复用 KlineChart，联动指数卡片 |
| 板块排行 | 改为左右 Top N 条状图（各自可滚动） |
| 资金流向 | 暂不实现 |

### 边界情况

| 场景 | 行为 |
|------|------|
| 非交易时段 | 使用缓存数据显示最近交易日数据，不刷新 |
| 全球 tab | 合并 A 股/港股/美股三大市场数据（取各市场前 5 指数 + 行业排行） |
| 指数 K 线加载中 | 骨架屏覆盖 K 线区域 |
| 涨跌停数据不可用 | 显示 "--"，不崩溃 |
| 快速切换市场 tab | 取消上次请求（loadSeq 守卫），避免竞态 |
| 资金流向不可用 | 该行隐藏，不显示空数据 |
