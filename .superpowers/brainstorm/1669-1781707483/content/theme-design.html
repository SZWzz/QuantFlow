设计决策

  • CSS Variables 方案：`:root` 定义变量，通过 `.theme-dark` / `.theme-light` class 切换
  • 暗色保持现有颜色不变
  • 亮色基于 Tailwind 灰色系 (#f0f2f5 / #fff / #111827)
  • 密度用 `.density-compact` / `.density-default` / `.density-comfortable` 控制
  • 所有 17 个面板自动适配，无需逐个修改
